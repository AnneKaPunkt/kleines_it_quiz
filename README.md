# kleines_it_quiz
Ein interaktives Konsolen-Quiz, das ich Rahmen meiner Umschulung zum Fachinformatiker in Anwendungsentwicklung entwickelt habe. Es dient zur praktischen Anwendung und Festigung der Python-Grundlagen sowie der Versionsverwaltung mit Git.

## Funktionen
- **Interaktiver Ablauf:** Abfrage von IT-Wissen über Multiple-Choice-Fragen.
- **Eingabe-Validierung:** Das Programm entfernt Leerzeichen und ignoriert Kleinschreibung (`.strip().upper()`), um Abstürze zu verhindern.
- **Dynamisches Punktesystem:** Automatische Auswertung und Anzeige der erreichten Punktzahl am Spielende.

## Gezeigte Grundlagen
- **Datenstrukturen:** Strukturierte Speicherung von Daten mittels Listen und Dictionarys (Schlüssel-Wert-Paare).
- **Kontrollstrukturen:** Effizientes Durchlaufendes Fragenpools mit einer `for`-Schleife und Logikprüfung per `if/else`.
- **Clean Code:** Übersichtliche Code_Strukturierung, sprechende Variablennamen und verzicht auf redundanten Code.

## Projekt starten
Um das Quiz lokal auf dem Computer zu starten, werden folgende Schritte ausgeführt:

1. Herunterladen der Datei `quiz.py`
2. Das Terminal oder die Konsole im entsprechenden Ordner öffnen.
3. Das Programm mit folgenden Befehl starten:
```bash
python quiz.py
```
